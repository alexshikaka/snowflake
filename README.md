# Котик на рабочем столе

Пиксельный котик гуляет по рабочему столу: ходит, сидит, оглядывается, поднимает лапку,
слушает музыку в наушниках, когда в Windows меняется песня. Иконка в трее: размер, экран,
зона прогулок, поверх или под окнами, автозапуск.

## Как установить

1. Откройте раздел **Releases** справа на этой странице.
2. Скачайте `CatPet-Setup-….exe` и запустите.
3. Python не нужен, права администратора не нужны.

Удалить: «Параметры Windows → Приложения → Котик на рабочем столе → Удалить».

## Как устроено

- `app/cat_pet.py` — программа (кадры встроены в файл).
- `installer/CatPet.iss` — установщик Inno Setup.
- `.github/workflows/build.yml` — GitHub сам собирает установщик при каждом изменении.
- Номер версии — в файле `VERSION`. Новая версия = поменять номер, установщик выйдет в Releases.
